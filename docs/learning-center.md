# 学习中心

## 范围

在现有 React / TypeScript / HashRouter 项目中扩展 Learn，不引入服务或新依赖。
知识目录覆盖15个领域、30个原创核心知识点；每课提供八段讲解、先修关系、难度、预计时长、指标与自测。
Beginner Level 0–4 为可选主线，课程不设解锁门槛。

## 数据与真实性

- `curriculum.ts`：课程、目录、先修和主线。课程参考 MIT OCW 和 Yale Open Courses，页面提供原课程与书目链接。
- `learningEvents.ts`：复用 `demoData.ts` 的 NewsItem，按事件ID、主题关键词与 termIds 映射课程，去重、忽略失效引用、排除演示新闻并按发布时间排序。
- 当前项目没有自动新闻抓取接口。本次没有新增实时新闻服务，页面明确显示已有快照与更新时间，不把构建时间、阅读时间当新闻更新时间。
- 原新闻数据未在此次全部独立核验。事件区区分原快照事实、机制参考、条件推演；课程机制不是实时市场共识调查。
- 后续真实抓取层应提供有来源的 NewsItem 及实际抓取时间；不要把未核验文本标记为实时数据。更换数组时继续使用映射函数。

## 交互

- `/learn`：事件拆解、可选路径、全目录、搜索与领域/难度/进度联合筛选。
- `/learn/:id`：可直接分享的独立课程；无效ID返回可恢复页面。
- 新闻与课程双向链接。无对应事件时明确显示空状态。
- `fid-learned-terms` 保存本浏览器进度；读取时校验数组、去重并忽略失效ID，存储受限时仍可阅读。
- 移动端单列目录与证据区，桌面双列目录、三列证据区；采用实色分区和细边框。

## 验证

运行 `npm test -- --run`、`npm run typecheck`、`npm run build`。
测试覆盖搜索筛选、课程导航与进度、错误存储、先修图、新闻映射及演示数据排除。
