- 首页增加“今日值得理解”。五张卡均明确标历史、日期范围和完成程度；原实时新闻区域与数据状态继续保留，不将案例插入实时数组。

## 新闻关联

最小机制按人工登记的 canonical URL + 正文/摘要 SHA-256 精确匹配，附关联理由，明确“主题背景，非同一事件”。支持一文多主题、一主题多新闻。内容版本变化或新闻失效即停止显示关联，等待人工复核；不使用关键词或 AI 自动归类。

本轮实际接通并浏览器验收两条现有 BBC 新闻：Jackdaw 气田供给决策→欧洲天然气历史主题；对加拿大关税法律争议→2018 关税成本主题。国家、时间及政策不同，不误称同一事件。

CNBC 数据中心新闻未满足当前 main 的新闻准入条件，因此没有强行展示或放宽规则。原型阶段 WMO/NOAA 近期资料仍仅作为人工整理的事件证据，不新增抓取源。

## 维护与剩余边界

1. 五个样本是人工维护的静态内容；没有开发自动事件发现、自动归并或全天候事件更新。
2. 新新闻的关联、来源状态、修订与课程映射需人工核对后提交。手工参考来源未伪造正文哈希或自动审核；`manual-reference` 与正式新闻已抓取哈希有区别。
3. 撤稿/变化的传播由显式状态与引用关系实现；没有额外后台自动监测历史引用网页。新闻侧仍遵循原有失效机制。
4. 四个基础样本没有伪装成已完成交互专题。情境选择正确不能证明真实初学者已掌握；仍建议下一阶段做少量读者复述测试。
5. PR #5（标签）和 #6（来源多样性）未合并，本分支不包含它们的改动。没有“恢复”或覆盖这些工作；合并顺序需按各自 PR 决定。

## CI、部署与回滚边界

PR 仅触发现有 check-pr 校验。Pages 只部署 main；更新数据的 push 触发路径是 scripts/package/workflows，本分支不修改这些路径。行情工作流仍 `if: false`。

未合并、未 dispatch 生产。代码层面具备合并候选条件，以远端 PR CI 最终结果为准。后续获准合并时正常 Pages 部署即可；若需回滚，revert 本 PR 的合并提交即可，正式新闻快照和课程进度格式未迁移，无数据回滚操作。
