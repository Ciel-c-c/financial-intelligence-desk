# 分层新闻上线验收

本阶段：中文来源事实摘要、英文来源中文总结、重要事件完整解读及新版审核。行情和研报不属于本阶段完成声明。

代码验收：测试先失败再通过；全套测试、TypeScript、Vite、数据契约和差异检查全部通过后发布。样式不改。

运行验收：真实检查至少一条中文来源摘要、一条英文来源中文总结和一条新版完整解读的来源、日期、事实归属及详情链接。特别检查否定、预测、币种、并列原因与个人影响维度，不能用模拟模型结果代替语义验收。

`public/data/news-acceptance.json`自动记录最近三个不同的定时周期。手动触发不冒充定时周期；任何一轮没有三类当前合格内容、超过共享预算或模型阶段报错，都继续标记pending。仅结构与运行条件通过时标记runtime-checked，不能把这个状态称为所有报道都已独立核验。

历史内容标记pending/approved/rejected并绑定来源哈希。已明确拒绝的内容不从旧reviewed-news文件恢复；传输/额度故障保留原日期及待审状态。原始媒体全文只在服务器阅读和处理，不写入公共快照。

当前验收状态：代码实施与实际上线核验进行中。尚未确认三个新版本定时周期成功，尚未宣称完整验收。
