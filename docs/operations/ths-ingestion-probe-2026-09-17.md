# 同花顺正文适配验证

2026-09-17 对公开列表与两篇文章进行了只读验证。PowerShell 返回 200 且包含正文、来源链接及页面版权信息；列表声明 GBK 编码，文章有独立正文容器与免责声明结束边界。

Node 原生 fetch 使用项目明确标识的 User-Agent 读取列表，返回 HTTP 200、正文长度 0。生产适配实测失败，不能称为已经接通自动采集。原因尚不能确定为反爬、客户端兼容性或其他服务器行为；没有绕过访问限制。

当前实现仅提供待验证适配器：限定文章域名和路径，校对列表日期与链接日期，去重，验证正文标题与结束边界；出版方名称必须与已知原始域名同时匹配。未知出版方及冒名链接拒绝读取为合格正文。公开快照剥离正文，只保留校验元数据，不公开转载。

GBK/GB18030 与 UTF-8 按响应头或 HTML 声明解码，未知或损坏编码失败，不猜测中文内容。单元测试不代表真实 Node 抓取已成功。因此来源保留于 pendingNewsSources，enabled=false。
