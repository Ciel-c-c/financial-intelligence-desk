# 金融资讯台：MVP 产品与技术方案

日期：2026-09-08。状态：用户已确认网站方向，并授权先初始化独立项目和连接 GitHub；业务界面尚未开发。

## 目标与范围

手机优先的个人金融阅读与学习工作台。以读懂资讯及其可能影响为核心，覆盖全球财经新闻、A股/港股/美股概览、新闻解读、每日 Brief、知识卡片及 PWA。不包含账户、真实交易、投资组合、社交、数据库或常驻大型后端。

## 技术选择

推荐 React + TypeScript + Vite + 普通 CSS，以静态站点交付，使用轻量路由和 PWA 插件生成 Service Worker。React 负责可复用阅读组件，TypeScript 约束新闻及分析数据结构，避免首版引入 UI 大型组件库及全局状态框架。

备选一：原生 TypeScript，依赖更少，但多页面阅读状态及组件复用需自行组织。备选二：Next.js，适合日后服务端聚合与动态生成，但当前部署和运行复杂度高于需求。首版选择 Vite。

## 页面与交互

底部三项导航：今日、Brief、学一点。新闻详情为二级页面；安装帮助使用轻量面板。

| 页面 | 内容 | 主要操作 |
| --- | --- | --- |
| 今日 `/` | 数据时间、A/港/美市场卡、全球资讯流、地区筛选、新闻搜索 | 筛选新闻、打开详情、进入 Brief |
| 解读 `/news/:id` | 来源、发布时间、原文链接、简明摘要、带术语标注的阅读段落、四类分析、因果链 | 点术语查看解释、切换标注、返回列表 |
| Brief `/brief` | 日期、重点事件、三地市场回顾、观察事项、每日知识 | 进入相关事件详情、切换已有日期 |
| 学一点 `/learn` | 利率、通胀、估值、分散投资等基础知识卡 | 搜索知识、展开例子、标记学过 |

详情页的事实、市场共识、AI 推演、风险分别有文字标签，不能只用颜色区分。市场共识需要可核验来源；缺乏证据时显示“暂无可靠共识资料”，不由模型编造。因果链每个节点包含通俗解释、成立条件及反例，使用“可能”措辞。原文链接始终可见；仅展示允许使用的原文摘录并标注解释，完整原文跳转阅读，不假设拥有全文转载权。

视觉采用浅暖灰背景、深蓝文字、青绿色重点色、清晰留白和卡片层级。手机 360–430px 优先，桌面限制阅读宽度。涨跌必须同时显示正负号和文字。支持键盘焦点、触控目标、减少动画及底部安全区。

## 数据边界与数据流

首版可运行界面默认使用随项目提供的结构化演示数据，所有新闻、行情、Brief 和分析都明确标注“演示”，显示内容日期，不能伪装实时资讯或在线 AI。此首版验证阅读闭环，不声称已完成自动聚合。

数据流：版本化 JSON → 数据适配器校验与标准化 → 页面查询/筛选 → 阅读组件。知识学习状态仅保存在 localStorage，保存失败时不阻断阅读。

数据实体：

- NewsItem：id、标题、地区、主题、来源名称/URL、发布时间、摘要、允许展示的摘录、术语关联、内容模式。
- Analysis：关联新闻、事实与证据、带来源的共识、推演节点/条件、风险/反例、生成时间与模式。
- MarketSnapshot：市场、指数名称、点位、涨跌幅、交易状态、行情时间/时区、来源、是否延迟、内容模式。
- Brief：日期、生成时间、关联新闻 ID、市场快照、观察事项、知识 ID、内容模式。
- KnowledgeCard：id、术语、简明定义、生活例子、常见误区。

真实运行扩展路径：授权新闻/RSS/行情接口 → 定时脚本去重、标准化 → 服务端调用 AI 生成有证据关联的分析 → 结构校验 → 发布静态 JSON → 前端复用现有适配器。密钥只能保存在任务运行环境或托管平台 Secrets，不能进入前端构建产物。接入前需确定供应商、授权、配额、更新时间和费用；不为界面演示擅自购买服务。

## PWA、缓存与异常

配置名称、独立窗口、start_url、scope、192/512 图标、maskable 图标及 Apple touch icon。缓存应用外壳和最近成功读取的数据，离线状态明确显示缓存时间。行情使用优先网络策略，旧数据不得显示为最新。更新可提示刷新，新 Service Worker 激活后清理旧缓存。

安装按钮在浏览器提供安装事件时启用；其他场景显示对应安装指引。手机安装与 Service Worker 正式验证需要 HTTPS 地址（本机 localhost 可用于开发）；本机 HTTP 局域网访问不能代替手机安装验证。

包括加载、空结果、缺失新闻、数据错误、离线与陈旧数据状态。历史 Brief 明确日期，不自动改成今天。
